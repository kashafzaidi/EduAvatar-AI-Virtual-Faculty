EduAvatar – AI Virtual Faculty 🎓

EduAvatar is a Generative AI based learning assistant that helps students learn from their own study PDFs.

Students can upload a PDF and interact with it like a virtual teacher. The application can explain topics, answer questions, generate quizzes, and show learning performance.

  Features

-  Upload and understand study PDFs
-  AI-powered explanations and Q&A
-  PDF-based question answering using RAG
-  Topic-wise quiz generation
-  Learning performance analytics
-  Interactive virtual faculty experience
  
Tech Stack

Python • Streamlit • Google Gemini • RAG • FAISS • PyMuPDF • Pandas • Scikit-learn • Matplotlib
